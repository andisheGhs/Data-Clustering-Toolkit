# Data Clustering Toolkit

A simple Python toolkit to compare popular clustering algorithms on synthetic datasets with visualization and performance metrics.

## Features
- Generates sample datasets (`make_blobs`, `make_moons`)
- Runs `KMeans`, `DBSCAN`, and `Agglomerative Clustering`
- Computes Silhouette Scores
- Visualizes clustering outputs side-by-side

## Run
```bash
pip install -r requirements.txt
python clustering_toolkit.py
